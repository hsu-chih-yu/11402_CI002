# LeetCode 62 - Unique Paths

## 題目描述
一個機器人位於一個 $m \times n$ 網格的左上角（起始點在下圖中標記為「Start」）。
機器人每次只能 **向下** 或 **向右** 移動一步。機器人試圖達到網格的右下角（在下圖中標記為「Finish」）。
請問從左上角到右下角總共有多少條唯一的路徑？

[題目連結](https://leetcode.com/problems/unique-paths/)

## 學習重點

- [x] 掌握網格類 DP 的狀態轉移方程式。
- [x] 處理基礎情況 (Base Case)：第一行與第一列的初始化。

## 解法思路：動態規劃

### 1. 狀態定義
令 `dp[i][j]` 為從起點抵達座標 $(i, j)$ 的總路徑數。

### 2. 轉移方程
機器人只能從「上方」或「左方」走過來，因此：
$$dp[i][j] = dp[i-1][j] + dp[i][j-1]$$
這本質上就是**帕斯卡三角形 (Pascal's Triangle)** 在網格上的應用。

### 3. 邊界初始化
- **第一列 (Top Row)**：機器人只能一路向右走，路徑數只有 1 種。
- **第一行 (Left Column)**：機器人只能一路向下走，路徑數也只有 1 種。
- 本實作透過 `vector<vector<int>> dp(m, vector<int>(n, 1))` 直接將所有格子預設為 1，巧妙地完成了邊界初始化。

## Code Structure
```cpp
#include <vector>

using namespace std;

class Solution {
public:
    int uniquePaths(int m, int n) {
        // 建立 m x n 的二維陣列，並將所有初始值設為 1
        // 因為第一列與第一行的路徑數永遠為 1，這樣寫可以直接完成初始化
        vector<vector<int>> dp(m, vector<int>(n, 1));
        
        // 從索引 (1, 1) 開始計算其餘格子的路徑數
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                // 狀態轉移：當前格子的路徑數 = 上方格子來源 + 左方格子來源
                dp[i][j] = dp[i-1][j] + dp[i][j-1];
            }
        }
        
        // 回傳右下角的數值即為總路徑數
        return dp[m-1][n-1];
    }
};
```

## 複雜度分析
- **時間複雜度**: $O(M \times N)$，遍歷整個 $m \times n$ 矩陣一次。
- **空間複雜度**: $O(M \times N)$，建立了一個與網格大小相同的二維陣列。
  *(進階優化：可使用 $O(N)$ 的滾動陣列優化空間)*

## 筆記與心得
- **數學解法**：這題其實是一個組合問題。從左上角到右下角總共需要走 $(m-1) + (n-1)$ 步，其中必須有 $(m-1)$ 步向下，$(n-1)$ 步向右。因此答案等於 $C^{(m+n-2)}_{(m-1)}$。
- **程式實作建議**：雖然數學公式很快，但 DP 的方法更具通用性，且能應對「網格中有障礙物 (LeetCode 63)」的變體。
